# AI-Based-Text-Extraction-Engine-by-Using-Computer-Vision-System-and-Voice-Readout
AI-Based Text Extraction Engine with Voice Readout: Built a real-time assistive system using Raspberry Pi, OpenCV, and Tesseract OCR to extract text from images and convert it into speech. Designed to aid visually impaired users, the solution is portable, cost-effective, and enhances accessibility.
